# PoseMaster — 3D Artist Mannequin

A free 3D poseable mannequin for artists. Click any joint and drag to pose it, or just type something like "running" or "kamehameha" and it snaps to it instantly.

## Features
- 17 moveable joints
- 30+ built-in poses — Basic, Combat and Power
- Pose Bot — type any pose in plain words
- Screenshot your pose as a PNG
- Works fully offline, no account needed

## How to run
```bash
npm install
npm start
```

## Built with
React 18 + Three.js
